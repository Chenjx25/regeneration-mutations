# Custom utilities

Place redistributable copies of the original custom mutation-screening utilities in this directory and point the species configuration files to them.

At minimum, the SNV driver requires:

- `fillVcfDepth.pl`
- `detect_mutations.pl`
- `vcf_process.pl`
- `maskVCF.pl`

See the root README and `UPLOAD_CHECKLIST.md` for the indel and false-positive assessment utilities. The core utilities were previously reported in Wang et al. (2019), Ren et al. (2021), and Wang et al. (2023).
