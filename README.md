# Metadata to deposit

Add one public sample manifest and the exact biological group-definition files used for each species. Sample IDs must match the IDs used in the deposited processed data.

Recommended files:

```text
arabidopsis_samples.tsv
arabidopsis_groups_*.txt
rice_samples.tsv
rice_groups_*.txt
liriodendron_samples.tsv
liriodendron_groups_*.txt
sample_id_mapping.tsv
software_versions.tsv
reference_checksums.tsv
filtering_stage_counts.tsv
```

Do not include local server paths, personal identifiers, or credentials.
